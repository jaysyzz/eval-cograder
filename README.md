# CoGrader Feedback Quality: Strength Acknowledgement Evaluation

## Research Question

Does CoGrader AI-generated feedback on grade 9 written responses specifically acknowledge student strengths across essay quality tiers?

- Does the strength acknowledgement rate decline with essay quality, or is it constant/high across all tiers?
- Is the strength acknowledgement rate consistent across different topics in ELA argumentative essays?

## Overview

Using Claude Sonnet 5, we generate 60 argumentative essays targeting the 9th grade level across three quality tiers (Strong / Developing / Weak) and 5 topics in ELA Argumentative Essays, with each topic fully crossed with all three tiers.

Each text is then run through CoGrader (based on the Smarter Balanced Argumentative Performance Task Writing Rubric Grades 6-11 and the 3-2-1 Feedback Style) to produce rubric-based feedback. Each generated text, along with its CoGrader feedback, is evaluated for **Strength Acknowledgement** using an LLM-based evaluator powered by **GPT-5.4**.

The evaluator assesses feedback across 5 features to determine whether the feedback names an authentic, specific strength present in the student's writing:

1. Presence of praise
2. Specificity
3. Anchoring to evidence
4. Process vs. trait framing
5. Warranted acknowledgement

### 1. ELA Argumentative Essay Topics

1. Should students be required to wear school uniforms?
2. Should schools ban cell phone use during the school day?
3. Should standardized testing be reduced or eliminated?
4. Should schools push back start times to later in the morning?
5. Should students be allowed to use AI tools (like ChatGPT) for homework?

## Rubric

Feedback is generated by CoGrader based on the **Smarter Balanced Argumentative Performance Task Writing Rubric Grades 6-11** (Common Core State Standards)
## Methodology

**Text Generation:** Essays are generated independently using an LLM (Claude Sonnet 5).

**Text Validator** Each essay generated by Claude Sonnet 5 is then evaluted by ChatGBT GBT 5.5 to verify if the generated essays by Claude align with its assigned quality. We prompted GBT 5.5 to act as a experienced 9th grade ELA teacher to grade the student papers and assign a holistic label: Weak, Developing, Strong and a grade letter.

**Feedback Generation:** Each essay is submitted to CoGrader, which returns rubric-based feedback that includes a score out of 10, a summary, 3 things you did well, 2 things to improve, 1 question I still have, and the rubric specific feedback

**Evaluation:** The [Strength Acknowledgement Evaluator]( https://docs.learningcommons.org/evaluators/feedback-evaluators/strength-acknowledgement) (powered by GPT-5.4) scores each feedback sample on 5 features:

1. **Presence of praise** — Does the feedback include any acknowledgement of strength at all?
2. **Specificity** — Is the praise tied to a specific element of the writing, rather than generic?
3. **Anchoring to evidence** — Does the praise reference a concrete example from the text?
4. **Process vs. trait framing** — Does the feedback praise the writing/process rather than making a trait-based judgment about the student?
5. **Warranted acknowledgement** — Is the praised strength actually present and accurate in the student's writing?
